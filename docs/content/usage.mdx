No keybind, nothing to operate. `/tchirp` only answers questions.

## What counts as a park kill

All three must be true as a player leaves a vehicle:

1. They were in a **front seat** — driver or front passenger.
2. The vehicle's **siren was on** at the last check before they left.
3. The vehicle's **model is in `Config.chirpAssignments`**.

The siren is sampled every 500 ms, and the exit is judged against the **previous** sample.

<Callout type="warning" title="A hand-killed siren can still chirp">
A siren switched off by hand and then left within the same 500 ms window counts as a park kill, and nothing can tell the two apart afterwards. When testing, **let the ELS park-kill the siren**.
</Callout>

## The front-seat rule

A front seat — driver or passenger — both arms and clears a chirp, and nothing chirps while one is occupied. The chirp plays from the vehicle, so it fades as you walk away.

## `/tchirp`

Open to anyone, no ACE. Read-only — there is no `/tchirpedit`. Two sidebar entries: **Status**, below, and **Feedback**, which sends one message to TIMMYG Studios rather than to this server's staff.

| Row | Answers |
| --- | --- |
| Will chirp on park | Has this car an entry, and which sound. With none it prints the model hash |
| Siren right now | On or off, **and which provider answered** |
| Chirping now | How many vehicles are on the list server-wide, as last heard |
| Silence … *N*m away | The one action. Only when something is chirping within 50 m |
| Provider · *N* models configured | The provider and timing from `config.lua` |

Every row above is on **Status**. The assignment key is the **spawn** name. On foot the first two rows become **Not in a vehicle**. **Silence** takes the nearest chirping car off the list, the same as someone getting in.

## What the server refuses

The server re-checks every park kill against its own `config.lua`:

| When the server can | It requires |
| --- | --- |
| see the vehicle and its model | **exactly** the tone that model is assigned. Another configured tone is refused, not corrected |
| see the vehicle, whose model has no assignment | nothing — refused outright |
| not see the vehicle at all | a tone this server has configured somewhere |

Both events are rate-limited at 12 per 10 seconds per player.

<Callout type="warning" title="Clearing a chirp is not ownership-checked">
A removal is accepted from any player. The worst a forged one does is stop a chirp early.
</Callout>

## Cleanup

Entries whose vehicle no longer exists are swept every 5 seconds, after a 5-second grace period. Stopping the resource releases every sound.
